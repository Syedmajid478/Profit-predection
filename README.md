Profit Prediction Using Machine Learning 📊

Overview

Profit Prediction is a machine learning project developed using Python to predict business profit based on startup-related data.

The project explores the relationship between business-related input features and profit using a trained machine learning model.

Features

- Predicts estimated business profit from input data
- Uses a machine learning model for prediction
- Includes a dataset for model development
- Includes saved model and encoding files

Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

Project Structure

- "profit_prediction.py" — Main prediction script
- "50_Startups (1).csv" — Dataset
- "random_model.pkl" — Saved model file
- "state_encoder.pkl" — Saved state encoder
- "requirements.txt" — Python dependencies

Getting Started

1. Clone the Repository

git clone https://github.com/Syedmajid478/Profit-predection.git
cd Profit-predection

2. Install Dependencies

pip install -r requirements.txt

3. Run the Project

python profit_prediction.py
